# ============================================================
# 用户多音字修正语料（用户可自行编辑，无需改代码）
# ============================================================
# 本文件与默认语料 overlay_override_risk.txt 并存：
#   - g2p_phoneme.py 启动/调用时自动加载并合并两处规则；
#   - 加载顺序：默认语料在前，本文件在后；
#   - 同一位置同时命中时，本文件的规则优先生效（可覆盖默认语料）；
#   - 修改本文件后保存即可生效（检测到文件变化自动重载，无需重启进程）。
#
# 每行一条规则，格式（与默认语料一致）：
#   上下文词 · 目标字: pypinyin默认=X → 强制=Y
# 说明：
#   - 上下文词：目标字所在的词/短语，文本中出现该词时才触发；
#   - 目标字：上下文词中要修正读音的那个汉字（必须出现在上下文词中）；
#   - pypinyin默认=X：仅作说明/参考，程序不校验，可不准确；
#   - 强制=Y：最终强制的读音，TONE3 数字声调格式（1~5，5 为轻声）；
#     韵母 ü 写作 v（如 lv3），程序会自动还原为 ü；
#   - 以 # 开头的行和空行会被忽略；
#   - 格式不兼容的行会被静默跳过，并在日志中提示（不影响其他规则）。
#
# 示例（可直接复制修改）：
#   结实 · 结: pypinyin默认=jie1 → 强制=jie2
#   地处 · 处: pypinyin默认=chu3 → 强制=chu4
#   高处不胜寒 · 胜: pypinyin默认=sheng4 → 强制=sheng1
# ============================================================
