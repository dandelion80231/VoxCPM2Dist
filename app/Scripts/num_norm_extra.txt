# num_norm_extra.txt — 用户自定义数字/文本归一化规则（可选，不建则完全不影响）
#
# 本文件由 text_norm_cn.py 在每次合成时自动加载（按文件修改时间热更新，改完即生效，
# 无需重启程序）。规则在「全角转半角之后、内置规则之前」执行：
#   写在这里的读法优先于内置规则；没写的问题词照走内置规则。
#
# ── 语法 ──
# 以 # 开头或空行 = 注释，忽略。
#
# 1) 字面替换：  原文 => 读法
#    对全文做精确子串替换（区分大小写），最安全，优先用这种。
#
# 2) 正则替换：  行首加 ? 前缀，  ?正则 => 替换
#    替换串支持 Python re 反向引用 \1 \2。正则写错只警告跳过该行，不影响合成。
#
# 注意：
#   - 音素块 {...}（如 {ni3}）在规则执行前已被保护，你的规则碰不到它。
#   - 读法里若仍含阿拉伯数字，会被后续内置规则继续转换（一般写纯中文读法即可）。
#
# ── 示例（去掉 # 即生效）──
# 3.14 => 三点一四
# v5 => 五
# 007 => 零零七
# 第3期 => 第三期
# ?0+(\d) => \1            ; 去掉前导零：007 -> 7（示例；注意会作用于任何位置）
